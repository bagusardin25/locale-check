One objective, run in every language

Kane CLI gets this plain-English objective once per language, with the placeholders filled in.

  1. Open any product, add it to the cart, open the cart and click the checkout button.
  2. Shipping step: fill in realistic test details for a customer in a {language}-speaking country. Verify that this step's Continue button is fully visible and that no other element overlaps it, then click it.
  3. Delivery step: type a delivery date about one week from today, in exactly the format the hint on the page shows. Verify that this step's Continue button is fully visible, that no other element overlaps it, and that its label is written in {language} words rather than a code-like key with dots (such as section.some_label). Then click it.
  4. Review step: keep the default payment method. Verify that the Place order button is fully visible, not cut off by its card, and that no other element overlaps it, then click it.
  5. Verify that the order confirmation with an order number appears.

If any verification fails, fail the test at that step. Do not work around a hidden or covered button with the keyboard.
